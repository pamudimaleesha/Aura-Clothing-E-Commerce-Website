# Aura Clothing Store - Fashion E-Commerce Website

Aura Clothing Store is a stylish and modern online fashion shopping platform for Sri Lanka. Built with PHP and MySQL, it features a responsive and user-friendly design using Bootstrap 5, providing customers with a smooth shopping experience from browsing trendy outfits to secure checkout.

## Features

- **User Authentication System**
  - Secure sign-up and login functionality
  - User profiles with order history
  - Role-based access (customers and administrators)

- **Fashion Product Management**
  - Browse products by fashion categories
  - Featured and trending collections
  - Product details with images, sizes, and descriptions
  - Search functionality for quick product finding

- **Shopping Experience**
  - Easy cart management system
  - Wishlist functionality for favorite fashion items
  - Responsive design for mobile, tablet, and desktop
  - Real-time cart and wishlist updates

- **Admin Dashboard**
  - Fashion product inventory management
  - Order processing and delivery updates
  - Category management
  - User management
  - Customer feedback monitoring

- **Customer Engagement**
  - Customer testimonials and reviews
  - Contact form for inquiries
  - Promotional sliders and fashion banners
  - Newsletter subscription section
